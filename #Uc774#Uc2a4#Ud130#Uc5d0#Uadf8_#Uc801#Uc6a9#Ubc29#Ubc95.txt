경성야록 · 이스터에그 「거꾸로 꽂힌 활자」 적용 방법
========================================================

■ 무엇이 바뀌었나
  · 기존 파일의 코드는 고치지 않았습니다.
  · 딱 하나, index.html 맨 아래 </body> 바로 윗줄에 아래 한 줄만 추가했습니다.
        <script src="sikjasil-egg.js"></script>
  · 새로 생긴 것: sikjasil-egg.js (파일 1개), sikjasil/ (게임 폴더 1개)

■ 방법 A — 통합본 쓰기 (가장 쉬움)
  1. 지금 쓰는 gyeongseong-yarok 폴더 이름을 gyeongseong-yarok_이스터에그전 으로 바꿔 보관합니다.
  2. 받은 「경성야록_통합본_이스터에그.zip」 을 풀어 그 폴더를 씁니다.

■ 방법 B — 지금 폴더에 직접 넣기 (팀원이 그사이 index.html을 고쳤다면 이쪽)
  1. 「넣을파일」 폴더 안의 두 가지를 경성야록 폴더(index.html 있는 곳)에 그대로 복사합니다.
       · sikjasil-egg.js
       · sikjasil  (폴더째)
  2. index.html 을 메모장/VS Code로 열고, 맨 끝의 </body> 를 찾습니다.
  3. </body> 바로 윗줄에 아래 한 줄을 붙여 넣고 저장합니다.
        <script src="sikjasil-egg.js"></script>
  끝. 다른 곳은 손대지 않습니다.

■ 확인하는 법
  · 반드시 서버로 열어야 게임이 켜집니다 (index.html 더블클릭으로 열면 게임이 안 뜸).
      폴더에서 터미널 →  python -m http.server 8765  →  http://localhost:8765
      (Claude Code 의 launch.json 에 이미 이렇게 설정되어 있음)
  · 메인 맨 아래 「제일집 · 긔록을 따라」 칸 밑에 판권 한 줄이 생깁니다.
      發行兼印刷所　京城野錄社 活版部　每夜 子正 前 組版
    여기서 活版部 의 '版' 한 자만 거꾸로 박혀 있습니다. (옆의 組版 의 '版'은 바로 박혀 있어 비교하면 보임)
  · 그 글자를 누르면 → 식자실 입구 → 「나려간다」 → 게임
  · 호외를 찍어 내면: 지면으로 돌아왔을 때 활자가 바로 서고 '校正畢' 도장이 찍힘
    3분이 다 되면: 활자는 거꾸로 남고 판권 줄에 '植字工 一名 未歸' 가 붙음
  · 처음 상태로 되돌려 다시 보고 싶을 때: 브라우저 개발자도구(F12) → Console 에
        localStorage.removeItem('yk-sikjasil')
    입력 후 새로고침

■ 참고
  · 휴대폰·태블릿에서는 게임 대신 "식자실은 PC에서만 열리오" 안내만 나옵니다.
  · 게임 원본(gyungsung-main)은 그대로 두었습니다. sikjasil 폴더는 원본을 사이트용으로
    빌드한 결과물이며, 하위 폴더에서도 그림·소리가 나오도록 경로 3곳(/assets, /audio)만
    상대경로로 바꿔 빌드했습니다. 쓰이지 않는 참고 이미지들은 빼서 약 8MB입니다.
  · 게임을 고친 뒤 다시 넣고 싶으면 Claude에게 게임 zip을 주고 "식자실 다시 빌드"라고 하면 됩니다.
